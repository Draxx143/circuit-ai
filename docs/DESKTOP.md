# CIRCUIT AI Desktop — نسخه صنعتی (Qt/PySide6)

## چرا دیگر Streamlit نیست؟
نسخه وب (Streamlit) برای نمونه اولیه بود و ذاتاً «سایت» است. نسخه صنعتی یک
برنامه دسکتاپ بومی است: پنجره مستقل، بدون مرورگر و بدون پورت شبکه، با
نوار کناری ثابت، نوار عنوان صفحه، نوار وضعیت دائمی (پایگاه داده/موتور/آفلاین)
و منوی برنامه — الگویی که در ابزارهای حرفه‌ای تست و اندازه‌گیری
(Keysight BenchVue و NI InstrumentStudio) استفاده می‌شود: پنل ناوبری ثابت،
داشبورد وضعیت در نگاه اول و نمایش دائمی وضعیت سیستم.

## BoardView (جدید)
صفحه «BoardView نقشه برد»: بازکردن فایل برد JSON/CSV یا عکس برد، زوم/پن با موس،
چرخش و نمایش Top/Bottom و حالت آینه‌ای، جست‌وجوی قطعه با فوکوس و هایلایت،
کلیک روی پین برای روشن‌شدن کل نت روی برد، جدول پین‌ها با نام نت، رنگ‌بندی
مقادیر دیودمد ثبت‌شده، ذخیره اندازه‌گیری هر پین (با اتصال اختیاری به پرونده
تعمیر)، افزودن قطعه با کلیک روی عکس برد، و پنل شماتیک (عکس یا صفحه اول PDF)
کنار برد. قالب فایل در `docs/BOARDVIEW_FORMAT.md` و برد نمونه آموزشی در
`data/sample_boards/` است.

## صفحات
داشبورد (کارت‌های زنده از SQLite + آخرین پرونده‌ها)، عیب‌یابی مرحله‌ای
(ساخت پرونده ← اندازه‌گیری ← اجرای موتور شرطی ← ثبت نتیجه آزمایش ← بستن پرونده)،
پرونده‌های تعمیر (جست‌وجو/جزئیات/بایگانی)، بانک قطعات (جست‌وجو + پایه‌ها + منابع)،
دانش مدار و قواعد (توپولوژی/قواعد/failure modeها/منابع)، محاسبات مهندسی،
مدیریت پایگاه داده (گزارش کیفیت/پشتیبان/بازیابی با دیالوگ فایل) و تنظیمات (تم روشن/تیره).

منطق برنامه (`core/` و `services/`، اسکیما ۴) بدون تغییر از نسخه وب استفاده
می‌شود؛ فقط رابط عوض شده است. هر دو رابط روی یک پایگاه داده کار می‌کنند.

## اجرا در Ubuntu 24.04
```bash
./run-desktop.sh --install   # یک بار: ساخت .venv-desktop و نصب PySide6 (اینترنت لازم است)
./run-desktop.sh             # اجراهای بعدی: بدون دانلود
```
اگر خطای کتابخانه گرافیکی دیدید (معمولاً روی نصب‌های حداقلی):
`sudo apt install libgl1 libegl1 libxkbcommon0 libfontconfig1 libdbus-1-3`

## نصب سیستمی با ‎.deb
```bash
./packaging/build_deb.sh          # خروجی: dist/circuit-ai_2.0.0_all.deb
sudo apt install ./dist/circuit-ai_2.0.0_all.deb
circuit-ai                        # یا از منوی برنامه‌ها: CIRCUIT AI
```
حذف بسته (`apt remove circuit-ai`) اطلاعات تعمیر را پاک نمی‌کند؛ داده‌ها در
`~/.local/share/circuit-ai/` هستند.

## ساخت فایل اجرایی تکی (PyInstaller)
```bash
./run-desktop.sh --install
./packaging/build_executable.sh   # خروجی: dist/CIRCUIT-AI
```
در محیط ساخت این نسخه، ساخت PyInstaller به‌علت نبود `libpython` اشتراکی
تکمیل نشد؛ روی Ubuntu با python3 سیستمی (که libpython دارد) اجرا می‌شود.
بسته ‎.deb در همین محیط ساخته و محتوایش بازبینی شد.

## تست‌ها

```bash
python -m pytest tests -q     # ۴۷ تست شامل ساخت همه صفحات Qt و جریان کامل عیب‌یابی
python -m desktop_app --smoke-test
```
