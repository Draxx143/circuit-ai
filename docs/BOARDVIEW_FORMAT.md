# قالب فایل برد BoardView ‏(circuit-ai-board/1)

مختصات بر حسب میلی‌متر است؛ مبدأ گوشه بالا-چپ برد و Y رو به پایین (مثل عکس برد)،
تا عکس و داده برداری روی یک دستگاه مختصات بنشینند.

```json
{
  "format": "circuit-ai-board/1",
  "name": "Pump controller rev B",
  "width_mm": 100, "height_mm": 80,
  "image": "board_top.png",
  "parts": [
    {"ref": "U1", "part_number": "DRV8825", "package": "HTSSOP-28",
     "side": "top", "x": 50, "y": 40, "rotation": 0, "w": 9.7, "h": 4.4,
     "pins": [{"pin": "1", "name": "VCP", "net": "VCP", "x": 46, "y": 38.5, "diode_mv": 700}]}
  ]
}
```

- `ref` برای هر برد یکتا؛ `side` فقط `top` یا `bottom`.
- `net` خالی یعنی پین بدون اتصال ثبت‌شده — حدس زده نمی‌شود.
- `diode_mv` اختیاری است و به‌عنوان اندازه‌گیری همراه فایل وارد می‌شود، نه حقیقت تأییدشده.
- راه دیگر ورود داده: دو فایل CSV ‏(parts.csv و pins.csv) از منوی BoardView.

## عکس برد بدون فایل نقشه
از «بازکردن عکس برد» می‌توان عکس PNG/JPEG برد را باز کرد و با حالت
«افزودن قطعه با کلیک روی برد» قطعات/نقاط تست را روی عکس ثبت کرد.
ابعاد پیش‌فرض عکس ۱۰px = ۱mm فرض می‌شود؛ برای برد واقعی، مقیاس را پیش از
ثبت اندازه‌گیری‌های مکانی با ابعاد واقعی برد تطبیق دهید.

## برد نمونه
`data/sample_boards/motor_control_demo.board.json` یک برد آموزشی برچسب‌خورده
(۲۷ قطعه، ۹۱ پین، ۳۱ نت) برای یادگیری محیط است و برد واقعی/تأییدشده نیست.
